### 2.1 OCR 方案与实测对比

候选引擎实测（同页对比）：

| 引擎 | p120（术语集正文页） | p006（索引页，密集小字） |
|---|---|---|
| tesseract 5 + jpn (tessdata_fast) | 部分可读，词条级错误多（例：`原西または動画`→误；`クイックチェッカー` 可读） | 几乎全噪 |
| macOS Vision（accurate 级） | 接近完美，词条头+释义连续可读 | 索引行可读但有行内穿插 |
| vision_analyze 工具（多模态） | **幻觉**：把术语页认成「国语词典」并编造词条（きつい等） | 未再测 |
| zhipu glm-4.5v（API） | 因生产 key 429 限流，未完成 | 未测 |

**选型：macOS Vision（VNRecognizeTextRequest, accurate）**。理由：本机可用、日文质量实测最佳、免费、坐标级输出（支持双栏重构）。tesseract-jpn 保留作对照与降级路径。
视觉模型核验改走「强校验自动化」路径（见 2.3），glm-4.5v 保留为可选人工核验通道（当前限流不打）。

### 2.3 OCR 质量评估（量化）

自动强校验——五十音单调性检查：
- 原理：术语集按假名序排列，若栏重构/词条切分正确，reading 序列应单调不减。
- 实测：直接比较得 225 违例 → 发现「拉丁字母词条按字母序排在假名块前」为书的固有排版 → 修正比较器后 210 违例 → 深挖发现剩余违例为三类混合：小写假名（ぁぃぅぇぉ）未入排序表、注音 OCR 误读（如「演出協会→清出処会」）、词条头未识别（释义并入了上一词条）。
- **210 个违例对已导出为人工抽检清单**（`data/processed/glossary_order_violations.jsonl`），不冒充人工已核。
- 结论：OCR 主干可用，边缘错误集中于注音与边界词条，需要（a）标准答案核验时逐条回看页面（b）评测集答案仅采用高置信词条。

## 3. Bilibili 视频实测结果

- 标题：【从零学动画01】日式动画全流程，动画第一课（UP：阿咪画不完）
- 时长 968s（16:08），1P，cid=30273310278。
- 简介：动画新人/毕业生/美术生向，日式动画业界流程分享。BGM 来自 SHIROBAKO OST。
- **CC 字幕：无**（player API `subtitle.subtitles = []`，`allow_submit=false`）。
- AI 字幕/总结接口：ai.bilibili.com 域名 NXDOMAIN；view/conclusion 接口未登录返回 -403。
- **采取的合法替代：下载公开视频音轨（yt-dlp，仅音频）→ 本地 whisper.cpp 转写**。
- 转写结果（实测）：whisper.cpp ggml-small（Metal 加速，31.2s 计算耗时），**315 段，覆盖 956.7s/968s（98.9%）**，中文质量抽检良好（开场白/结尾完整可读，专业词偶有谐音如「作画积极」=「作画 mad/几何」不确定项已在块级标注）。已切分为 **12 个带时间戳的视频块**（data/processed/video_chunks_raw.jsonl）。
- 视频内容与选题关系：讲解日式动画全流程（脚本→分镜→layout→原画→中割→上色→摄影→剪辑），明确「跳过前期设定企划与声音，只讲实际画面制作」，与方案A 的流程/依赖维度直接互补（中文术语口径 vs 书的日文术语口径）。
- 失败记录（如实）：faster-whisper 因 PyAV 19 API 变更（`metadata_errors` 参数移除）无法解码音频；av==14 源码编译失败（缺 pkg-config）；openai-whisper 因 numba/llvmlite 无 py3.14 wheel 不可装。**全部改走 whisper.cpp CLI**。
