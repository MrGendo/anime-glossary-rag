Layout / 原画 / 动画（動画）职责边界
本知识库的小 topic（边界）：日式动画制作中 Layout（レイアウト）、原画、动画中割（動画・中割り） 三个环节的职责边界、输入输出、上下游交接与易混术语辨析。相邻环节：分镜（絵コンテ）、演出、作画监督（作画監督）、动画检查（動画検査）、上色（仕上げ）、制作进行（制作進行）等。不含：声优、音乐、宣发、商业模式、动画史。
